# Final_Project

A console-based roguelike dungeon crawler written in C#. Each level procedurally generates a randomly sized map containing an entry and exit, hidden traps, a treasure chest, and an enemy, which the player must navigate using keyboard movement.

Combat is turn-based: stepping next to an enemy triggers an exchange of damage based on the player's and enemy's stats, which scale with dungeon depth and a selectable difficulty level. A menu system lets the player customize their character (name, gender, avatar) and review game options before starting a run.

Built as a from-scratch console game using only the .NET base class library, with no external dependencies.
